二、核心思想：把”找不同”变成训练任务

2.1 一个通俗比喻

想象一个班里有 64 个学生，每人拍两张照片：一张正脸、一张侧脸（这就是同一张图的两种数据增强视图）。任务是：在不看姓名的前提下，把同一个人自己的两张照片认成一对，把别人的照片都推开。

  • 同一张图的两个增强视图 = 正样本对（positive pair）；
  • 其他所有图的视图 = 负样本（negative）；
  • 网络要学的就是：同源特征靠近、异源特征远离。

这个任务不需要任何人工标签——“是不是同一张原图”这个信息，数据自身就带着。这正是 P2 定义的”用数据的内在结构替代显式标签”。

2.2 严格定义

给定无标注数据集 $\mathcal{D}={x_i}_{i=1}^{N}$，从同一 mini-batch 中取 $N$ 张图。对每张图 $x$ 独立采样两次随机增强 $T_a,T_b\sim\mathcal{T}$，得到两个视图：

$$ \tilde{x}_i=T_a(x_i),\qquad \tilde{x}_j=T_b(x_i) $$

（视图对记为 $(i,j)$，二者互为正样本；其余 $2N-2$ 个视图全部是负样本。）

编码与投影：

$$ h_i=f_\theta(\tilde{x}_i),\qquad z_i=g_\phi(h_i)=\frac{W_2\,\sigma(W_1 h_i)}{\big\|W_2\,\sigma(W_1 h_i)\big\|_2} $$

其中 $f_\theta$ 是 ResNet backbone（输出 $h$），$g_\phi$ 是投影头（MLP，输出 $z$ 并做 L2 归一化）。损失只在 $z$ 空间计算。

三、InfoNCE / NT-Xent 损失详解

3.1 PPT 上的原始公式

画面（P3_220.png）给出的公式与流程是：

  • 正向流程：数据增强 $\pi(\cdot)$ → 两个视图 $x^{+}_i,\ x^{+}_j$ → ResNet $f(\cdot)$ → $h_i,h_j$ → MLP $g(\cdot)$ → $z^{+}_i,z^{+}_j$；
  • 损失：
$$ \mathcal{L}_{\text{infoNCE}} =-\log\frac{\exp\big(\mathrm{sim}(z_i,z^{+})/\tau\big)} {\exp\big(\mathrm{sim}(z_i,z^{+})/\tau\big)+\sum_{j}\exp\big(\mathrm{sim}(z_i,z^{-}_j)/\tau\big)} =-\log\frac{\exp\big(\mathrm{sim}(z_i,z^{+}_i)/\tau\big)} {\sum_{j}\exp\big(\mathrm{sim}(z_i,z_j)/\tau\big)} $$
  • 相似度：$\mathrm{sim}(z_i,z_j)=\dfrac{z_i\cdot z_j}{|z_i|,|z_j|}$，即余弦相似度，取值 $[-1,1]$。

页面上还标注了两个关键词：Softmax 与 cosine——意思是”把相似度除以温度、做 Softmax 变成概率分布，再取负对数”。这其实就是一次**$2N$ 类的分类**：给定锚点 $z_i$，正确类别是它的正样本，其余全是干扰项。

图 1：P3_220.png（03:40）。PPT 上半部是数据增强→ResNet→MLP 的流程图，中部是 InfoNCE 的两种等价写法（显式写出负样本项 / 写成全部样本求和），下部给出余弦相似度定义，并标注 Softmax 与 cosine。

3.2 逐项拆解：为什么这个式子”拉近正样本、推远负样本”

  • 分子 $\exp(\mathrm{sim}(z_i,z^+)/\tau)$：正样本相似度越高，分子越大，$\mathcal{L}$ 越小 → 拉近；
  • 分母中的 $\sum_j \exp(\mathrm{sim}(z_i,z_j)/\tau)$：任意负样本相似度越高，分母越大，$\mathcal{L}$ 越大 → 惩罚”撞脸” → 推远；
  • 因为做了 Softmax，优化的本质是相对概率：把正样本在所有候选中”排第一”的概率提到 1。

这就是 AI 大纲 00:53 的原话：”使用 InfoNCE 损失函数最小化正样本距离，最大化负样本差异”。

3.3 温度系数 $\tau$ 到底在干什么

$\tau$（temperature）通常取 0.07–0.5，SimCLR 原论文用 0.5（注意：不同实现默认值不同，代码里要显式指定）。

  • $\tau$ 很小：除以小数相当于放大相似度差异，Softmax 变得极其尖锐，模型只盯着最难的负样本（hard negative），学到的特征判别性强，但训练不稳定、容易崩；
  • $\tau$ 很大：分布被抹平，所有负样本权重接近，梯度平缓，判别性弱。

AI 大纲 03:39 的表述是”通过温度系数调节相似度计算，结合 Softmax 实现高效对比学习”。一句话记忆：$\tau$ 是”关注最难负样本”的旋钮。

3.4 NT-Xent 的对称化写法

SimCLR 论文把它叫 NT-Xent（Normalized Temperature-scaled Cross Entropy）。工程上会把 $(i,j)$ 与 $(j,i)$ 两个方向都算一遍再平均：

$$ \mathcal{L}=\frac{1}{2N}\sum_{k=1}^{N}\Big[\ell(2k-1,\,2k)+\ell(2k,\,2k-1)\Big], \qquad \ell(i,j)=-\log\frac{\exp\big(\mathrm{sim}(z_i,z_j)/\tau\big)}{\sum_{k\neq i}\exp\big(\mathrm{sim}(z_i,z_k)/\tau\big)} $$

下标 $(2k-1,2k)$ 的写法来自”同一张图的两次增强在 batch 里相邻排列”。对称化的意义是让每个样本既当锚点、又当正样本，监督信号翻倍，训练更稳。

四、SimCLR 的四个关键设计

4.1 设计一：数据增强组合（决定成败的第一要素）

图 2：P3_380.png（06:20）。PPT 展示 a)–j) 共 10 种增强在同一张蝴蝶图上的效果：a) Original image（原图）、b) Crop and resize（裁剪+缩放）、c) Crop, resize, and flip（裁剪+缩放+翻转）、d) Color distortion (drop)（颜色扰动-丢弃通道）、e) Color distortion (jitter)（颜色扰动-抖动）、f) Flip（翻转）、g) Cutout（随机遮挡）、h) Gaussian noise（高斯噪声）、i) Sobel filtering（边缘滤波）、j) Gaussian blur（高斯模糊）。

SimCLR 论文的结论（也是本节重点）：单独一种增强效果都一般，最有效的是”随机裁剪 + 颜色扰动”的组合。原因很直观——

  • 随机裁剪会改变物体在画面中的位置与尺度，逼网络学平移/尺度不变的语义特征；
  • 颜色扰动会破坏颜色直方图这条捷径，逼网络别靠”这张图偏蓝”来认图；
  • 单独用裁剪，网络可以靠颜色匹配两端；单独用颜色扰动，网络可以靠局部纹理匹配两端；两者叠加才真正逼出语义。

而 Cutout、高斯噪声、Sobel、高斯模糊这些，在论文的消融里收益很小甚至有害（它们破坏了信息但没带来不变性）。

4.2 设计二：投影头（Projection Head）

图 3：P3_515.png（08:35）。PPT 为 SimCLR 框架图：同一张图 $x$ 经两次增强得到 $x^{+}_1=T(x)$、$x^{+}_2=T(x)$，分别过 Encoder f(·) 得到 $h_1=f(x^{+}_1)$、$h_2=f(x^{+}_2)$，再经 Projection Head (MLP) 得 $z_1=g(h_1)$、$z_2=g(h_2)$，最后计算 Contrastive loss: Maximize Similarity。图注：Chen et al., ICML 2020。

关键点：损失在 $z$ 上算，下游用的是 $h$。为什么要多这一层 MLP？

  • 对比损失会破坏一部分对下游有用的信息（比如颜色、朝向），因为它强行要求这些被增强破坏掉的东西”不变”；
  • 把这部分”损耗”转移给可丢弃的投影头 $g$，backbone 的 $h$ 就能保留更完整、更通用的表示。

论文的消融显示：去掉投影头，线性评测精度掉 10 个点以上；且 $g$ 用非线性（ReLU）比线性好。

图 4：P3_595.png（09:55）。同一框架图的下游视角：预训练完成后丢弃 Projection Head，把 Base encoder（ResNet）接 Downstream Tasks 使用。这正是 P2 讲的”脚手架任务头用完即弃”。

4.3 设计三：超大 batch（负样本数量）

AI 大纲 09:53 的原话是”批量增大提升负样本多样，训练时长与网络规模增强效果”。SimCLR 原文用 4096–8192 的 batch（TPU），原因：在一个 batch 内，$N$ 张图产生 $2N$ 个视图，每个锚点的负样本数是 $2N-2$——batch 越大，负样本越多、越多样，InfoNCE 的”分母”估计越充分。

但这个要求对普通实验室很不友好：8 卡 32G 也未必跑得动 4096。这正是下一讲 MoCo 的切入点——用”队列 + 动量编码器”把负样本池和 batch 解耦。

4.4 设计四：大模型 + 长训练

论文发现对比学习特别吃容量和训练步数：ResNet 从 50 放大到 152、甚至 4× 宽度，训练从 100 epoch 拉到 1000 epoch，收益都在持续上涨（这与有监督学习的”过拟合拐点”完全不同）。所以对比学习时代的共识是：自监督不怕大、不怕久。

5.3 InfoNCE / NT-Xent 损失（含逐行注释）

它与公式的对应关系：sim[i][j] = sim(zi,zj)/τ 是 logits；targets[i] 是正样本列号；cross_entropy 内部先 log_softmax 再取目标类别 → 得到 $-\log\frac{\exp(\mathrm{sim}^+/\tau)}{\sum_j\exp(\mathrm{sim}_j/\tau)}$；因为 $i$ 和 $i+N$ 两行都参与了平均，天然实现了 NT-Xent 的对称化。

5.4 训练循环与数据组织（双视图拼 batch）

三个工程细节（容易踩坑，务必按此设置）：

  1. batch_size 要”够大”：单卡做不到 4096，就按显存取最大值（如 256/512），并把 temperature 稍调大一点缓解负样本不足；
  2. 一定要 drop_last=True：否则最后一个 batch 的 $N$ 变小，负样本统计和 targets 索引容易错位；
  3. 拼 batch 的顺序（前 view1、后 view2）必须与 targets 的构造一致，否则”正样本”会指到别人身上，训练直接失效。

七、易错点与面试追问

易错点 1：负样本不是”另一类的图”。 对比学习完全不知道类别，batch 里除正样本外的所有视图都是负样本，其中很可能包含同类别的猪和猪——这属于”假负样本（false negative）”，是后续 MoCo v3 / DINO 等工作的改进方向。

易错点 2：损失不算在 backbone 输出 $h$ 上。 一定在投影头输出 $z$ 上算；下游用 $h$。搞反了会显著掉点。

易错点 3：忘了 L2 归一化。 余弦相似度 = 归一化后的内积。不归一化时相似度会随特征模长漂移，等价于温度失效。

易错点 4：p=1 的翻转不是必须。 画面里写 RandomHorizontalFlip(p=1) 只是演示”每次必翻”的效果；真实训练用 p=0.5，否则两个视图永远同向，丢掉了翻转不变性。

易错点 5：温度不是学习率。 $\tau$ 不能靠 scheduler 随便衰减，它是损失函数的一部分，通常整轮训练固定（0.07–0.5）。

易错点 6：只堆一种增强。 只用裁剪 → 靠颜色匹配；只用颜色扰动 → 靠纹理匹配。必须”裁剪 + 颜色”组合，这是 SimCLR 消融里最硬的结论。

面试追问 1：SimCLR 的核心贡献是什么？
答：三件事——① 证明数据增强组合（裁剪+颜色扰动）是对比学习效果的第一决定因素；② 引入可丢弃的 MLP 投影头，保护 backbone 表示；③ 证明了大 batch + 长训练 + 大模型的 scaling 规律，把自监督线性评测推到接近甚至超过有监督。

面试追问 2：InfoNCE 为什么叫”Info”？
答：它可以被解释为”最大化锚点表示与正样本之间的互信息下界“。从实现上看就是一个 $2N$ 类的 Softmax 交叉熵，把”找出正样本”当作分类任务。

面试追问 3：SimCLR 最大的工程痛点？
答：负样本完全依赖 batch 内样本，因此必须超大 batch（4096+），显存和通信成本极高，而且负样本的”新鲜度”随 batch 结束即丢失。MoCo 用”队列存历史负样本 + 动量编码器保持特征一致性”来解除这个绑定。

面试追问 4：为什么对比学习要用余弦相似度而不是欧氏距离？
答：两者在特征归一化后等价（$|z_i-z_j|^2 = 2-2\cos$）。用余弦可以去掉模长这个自由度，让 Softmax 的温度只控制”方向差异”，训练更稳定。

八、本节小结

  1. 对比学习用同一张图的两次随机增强构造正样本对，其余全为负样本，无需人工标签；
  2. 损失用 InfoNCE：$-\log\frac{\exp(\mathrm{sim}(z_i,z^+)/\tau)}{\sum_j \exp(\mathrm{sim}(z_i,z_j)/\tau)}$，本质是 $2N$ 分类的 Softmax 交叉熵；对称化后即 NT-Xent；
  3. 温度 $\tau$ 控制对 hard negative 的关注程度；余弦相似度 + L2 归一化是标配；
  4. SimCLR 四要素：裁剪+颜色扰动的强增强组合、MLP 投影头、超大 batch、大模型长训练；
  5. 代码落地三件事：① ColorJitter + RandomResizedCrop + GaussianBlur 的 Compose（画面代码要补逗号）；② masked_fill_(-inf) 屏蔽对角线的 NT-Xent；③ 双视图拼接 torch.cat([v1,v2]) 与 targets 索引严格对齐；
  6. 遗留问题：负样本被 batch size 绑架——这直接引出下一讲 MoCo（队列 memory bank + 动量编码器）。
