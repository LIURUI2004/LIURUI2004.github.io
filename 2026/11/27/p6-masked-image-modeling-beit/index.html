二、先站到高处看：自监督学习的三条路

P2 一开头就把自监督学习的范式分成三类，本节是这条主线的”第三块拼图”：

路线 核心思路 代表方法 对应分P
基于前置任务（Pretext Task） 人工设计一个”假任务”，标签由数据本身变换而来 图像拼图 Jigsaw、旋转预测 Rotation、上色 Colorization P2
基于对比学习（Contrastive Learning） 同一张图的两个增强视图拉近，不同图推远 SimCLR（P3）、MoCo（P4/P5）、MoCo v3（P8）、DINO（P9） P3–P5、P8
基于掩码重建（Masked Image Modeling） 遮住图像的一部分，让网络把它”还原”出来 BEiT（本节）、MAE（P11） P6、P11

讲师在 03:54 的全章总结里把三者的关系说得非常清楚：

“基于前置任务的方法呢，是自监督学习当中最早的一系列方法的一个统称，它提出了各种各样的策略来实现’在没有标签的情况下我如何来训练这个网络’。然后基于对比学习的方法呢，就是说我从数据当中需要构造一对正负的样本，来让网络将正样本拉近、而负样本拉远，从中呢学习到有用的一个视觉的信息。那么最后呢基于掩码重建的方法呢，就是说我通过把图像中的一部分给 mask 掉，然后我们重建来学习到的这样一个视觉信息。”

紧接着一句很重要的判断——后两者其实也算前置任务的一种：

“后面这两种呢其实也算是一类前置任务，他们都是设计了一套方案来实现’我从数据集本身来创造出标签’，来让网络无监督的学习。但是由于后面两种方法它的这个实验效果非常优异，也是第一次超过了有监督学习的性能，所以说得到了非常广泛的研究和应用。”

这段话给出了分类的本质判据：三者都是”自己造标签”，区别只在于造标签的方式——前置任务是”变换题型”（旋转几度、拼图在哪），对比学习是”造正负样本对”，掩码重建是”造填空答案”。而”第一次超过有监督学习”这个判据，正是对比学习与掩码重建从”众多前置任务之一”跃升为”独立范式”的转折点。

三、MIM 的思想来源：BERT 的完形填空

讲师开场就把出处点明：

“这类方法的思想呢其实来源于 NLP 当中的 BERT。在 BERT 中的一个很重要的自监督任务呢是完形填空——就是我们随机把输入序列当中的某些单词给 mask 遮盖掉，然后让网络去预测输出被 mask 掉的内容。那么从这个任务当中呢，网络它就可以学习到 NLP 语句当中的上下文的这种特征。”

把这句话拆成”任务—监督信号—学到什么”三要素：

要素 NLP（BERT） CV（BEiT）
输入单元 单词 token（词表 30522） 图像 patch → 视觉 token（词表 8192）
遮盖方式 随机遮 15% 的 token，替换为 [MASK] 随机遮约 40% 的 patch，替换为可学习的 [MASK] embedding
监督信号 被遮位置的原始单词 id 被遮位置的原始视觉 token id（dVAE 产出）
学习目标 上下文语义 图像块的语义/结构（而非像素纹理）
输出层 MLP + softmax 分类到词表 Linear + softmax 分类到视觉词表

讲师随后补了一句方法论层面的感慨，对做研究的人很有启发：

“既然说 NLP 领域中这种’把一部分 mask 掉再重建’的方法那么有效，那么肯定就会有人想到，能不能把相似的思想给迁移到我们的 CV 当中。多做科研呢就是这样的，我们很多时候把其他领域的东西给迁移过来，其实就可以做出足够的一个创新性。”

为什么”迁移”在 CV 里不是照抄？ 关键差异在于离散 vs 连续：语言天然是离散符号（单词就是词表里的一个 id），”预测被遮的词”天然是一个分类问题；而图像像素是连续值，”预测被遮的像素”是一个回归问题，且像素级的回归目标（MSE）倾向于让模型去拟合高频纹理与噪声，学到的表征反而不语义。BEiT 的核心贡献就是：先给图像造一个”词表”，把连续重建变成离散分类——这就是下一节的 tokenizer。

四、BEiT 的完整流程：从切块到分类

图 1：P6_40.png（00:40）。PPT 页”基于掩码重建 - BEiT”，左侧是 BEiT 架构图（输入图像 → patch 序列 → 掩码 → Transformer Encoder → Masked Head），右侧是被框出的 MIM 目标函数公式 。

讲师用约 40 秒把整条流水线讲了一遍，原话拆解如下：

“类似于 BERT 呢，我们可以将输入的图像呢给它切成很多个 patch，然后呢我们随机地去 mask 掉一些。那所谓的 mask 的话，其实就是把它替换成一个可以学习的一个编码。那把它展平以后呢，每一项呢其实就是这边的 patch embedding。然后呢，我们在它前面呢去加上一个这个特殊的 token，叫做 special token。那么后面的这一部分呢，无非就是 Vision Transformer 的一个结构，我们给每一个 patch 一个位置的编码。那经过这个基于 ViT 的这样的一个多层的 encoder 的结构之后呢，最后我们要去预测每一个被 mask 的位置，它原先是什么。”

对应成流水线（以 224×224 输入、16×16 patch 为例）：

两个”特殊 token”别混：

  • [CLS] special token（④里加在最前面）：这是 ViT 用于下游分类的全局表征位，BEiT 预训练阶段它也参与，但不参与 MIM 损失；
  • [MASK] token（③里替换被遮 patch）：可学习的向量，作用是”告诉网络这里被遮了”。

位置编码为什么必须有：因为被遮位置的”答案”依赖于它周围的内容与它在图中的位置，去掉位置编码，模型无法知道”第 3 行第 5 列的那个洞”应该填什么，这个任务就退化成”随便填一个语义合理的块”，学不到空间结构。

图 2：P6_70.png（01:10）。PPT 页，BEiT 架构图旁标注论文信息（Bao et al., BERT Pre-Training of Image Transformers），下方为”Masked Image Modeling”标题，讲师在此处讲”把思想从 BERT 迁移到 CV”。

五、tokenizer 化：把”重建像素”变成”预测单词”

讲师在这里停顿强调了一次，是本节的技术核心：

“这篇文章的方法呢，就是说我把图像给进行了一个 tokenizer 化，也就是说对于每一个 patch，我都把它映射成一个视觉的 token，也就是说都是一个个代码。那我预测的时候呢，就去预测这个代码。那对于每一个被遮盖掉的地方呢，我都把它看成是一个分类的一个任务。比如这个 ‘234’ 的这样的一个块，它对应它原先的 patch，那我再把它 mask 掉以后呢，我对它分类，我就希望它预测成 234 这个类别。”

图 3：P6_125.png（02:05）。PPT 页，BEiT 可视化：展示图像 patch 与视觉 token 编号（如 234、71 等）的一一对应，说明”每个 patch 都有一个专属的词”。

图 4：P6_180.png（03:00）。PPT 页，用圈选的方式标出”被 mask 的 patch 位置”与”应当预测出的 token 编号”之间的对应关系，讲师同步讲解”Z_i 就是预测得到的视觉 token，比如这个 234”。

这一步改写了任务的性质：

传统像素重建（AE / MAE 之外的做法） BEiT 的 token 分类
预测目标 16×16×3 = 768 个连续浮点数 1 个离散 id（0~8191）
任务类型 回归（MSE / L2） 分类（交叉熵）
损失关注 像素级逐点差异，被纹理/光照主导 语义级”这是哪种块”
与 BERT 的可比性 无 完全同构，可直接复用 BERT 的整套训练技巧

一句话理解：BEiT 相当于先给图像造了一本”视觉词典”（8192 个词），把每张图翻译成一段”视觉句子”，然后让模型做视觉完形填空。这正是讲师所说”它就是一个一个代码”的含义。

6.2 逐层读懂这个 max

讲师把三层结构讲得很有条理，照他的顺序：

“那我们肯定是希望是说，第 个位置的这个东西通过最后的这个分类器之后，那它是 的概率要最大，因为最大的话就说明它是预测正确了，所以呢最外面呢是一个 max。那么里面这个求和符号呢，是所有被 mask 掉的地方，也就是说我希望所有被 mask 掉的这个地方，它都预测对，那这样的话我加起来的和就越大。而外面呢还有一个求和，这个 呢是说所有的训练数据。”

于是三层含义是：

  1. 最内层 ：单个洞填对的概率。 越大越”自信地填对了”。
  2. 中间层 ：一张图上所有洞的总得分。用 而不是原始概率，是为了把”概率相乘”变成”对数相加”——否则 ，80 个洞连乘会数值下溢，也让梯度被极小值主导。
  3. 最外层 ：整个数据集（batch）的总得分。所有样本一起最大化。

七、dVAE tokenizer：那本”视觉词典”是怎么造出来的

讲师在 P6 只在画面上带过 tokenizer（字幕里说”我把图像给进行了一个 tokenizer 化”），并未展开其内部结构；下面按 BEiT 论文与 DALL·E 的 dVAE 原文补充，作为本节的知识延伸。

7.1 为什么需要 dVAE 而不是随便聚类

要让”预测 patch”变成”分类问题”，必须满足三个条件：

  1. 离散：每个 patch 有确定的类别 id（分类的标签）;
  2. 可枚举：词表大小有限（8192），否则 softmax 无法计算；
  3. 可逆：从 token 能大致还原图像内容，否则”token 化”就是有损编码，学到的语义不可靠。

直接用 K-means 给 patch 特征聚类也能得到离散 id，但不可逆、且对光照/噪声极其敏感。dVAE（discrete VAE）同时满足三点。

7.2 dVAE 的结构与训练

图 5：P6_255.png（04:15）。PPT 页，BEiT 训练流程要点，其中讲到用 dVAE 把图像转为视觉 token（visual tokenizer）这一步。

dVAE = 编码器 + codebook + 解码器，是一个独立训练、训练完冻结的小型自编码器：

关键设计点：

设计 原因
用 Gumbel-Softmax 采样 argmax 不可导，Gumbel-Softmax 提供”硬前向 + 软反向”的可导近似，让 VAE 端到端训练
词表大小 8192 太小 → 大量不同 patch 被压成同一 token，重建目标退化（学不到细节）；太大 → 分类头参数爆炸、预测过难。8192 是论文选定值
KL 正则到均匀先验 迫使 codebook 中各 token 使用次数均衡，避免”少数 token 包打天下”（codebook collapse）
训练后冻结 若 tokenizer 随 BEiT 一起更新，MIM 的”答案” 会随之漂移，任务变成移动靶，训练不稳定

这就是 BEiT 与 MAE 的根本分歧点：BEiT 说”我要预测语义词，所以先学一个词典”；MAE 说”我不需要词典，直接回归像素就行，而且只编码可见 patch 以省算力”。两者在 2022 年前后各有拥趸，最终 MAE 因实现更简单、扩展性更好而影响更大；BEiT v2 后来改用CLIP 或 BEiT 自身的中间层特征当 tokenizer，绕开了 dVAE 这个额外组件。

八、为什么这条路能”超过有监督学习”

图 6：P6_230.png（03:50）。PPT 页，BEiT 与 Masked Image Modeling 的总结要点，讲师在此处转入全章三种方法的回顾。

讲师在总结时给出的判据是实验结果，而非理论优越性：

“由于后面两种方法它的这个实验效果非常优异，也是第一次超过了有监督学习的性能，所以说得到了非常广泛的研究和应用。”

从机制上解释，”掩码重建”为什么可能比”对比学习”学到更丰富的东西：

维度 对比学习（MoCo/SimCLR） 掩码重建（BEiT/MAE）
监督信号的密度 稀疏：一对图只产生 1 个标量相似度（或 1 行 4097 个 logits 里只有 1 个正） 密集：一张图 196 个 patch、遮 40% 就有约 78 个分类任务，每个都是 8192 类
学到什么 全局判别性（”这两张图是不是同一张”） 局部结构与语义（”这块该长什么样”）
对数据增强的依赖 极强（增强策略不对，正样本对就没意义） 弱（遮哪、遮多少本身就是”增强”）

9.2 高频追问

Q1：BEiT 为什么不直接回归像素，非要先训练一个 dVAE？
A：像素是连续高频信号，MSE 回归会把大量容量浪费在纹理、噪声、光照上，学到的是”低级视觉”而非语义；且回归目标是”平均的模糊块”，与 BERT 的分类式完形填空不同构。用 tokenizer 把图像离散化为”词”，把任务变回分类，既对齐了 BERT 的范式，又迫使模型预测语义类别而不是细节像素。

Q2：BEiT 与 MAE 的核心差异？
A：三点。① 预测目标：BEiT 预测离散 token（分类），MAE 预测像素（回归）；② 编码方式：BEiT 编码全部 patch（含 [MASK]），MAE 只编码可见 patch（因此训练快 3 倍以上、且不引入 [MASK] 造成的训练-推理不一致）；③ 是否需额外模型：BEiT 需要先训 dVAE，MAE 不需要。

Q3：mask 比例为什么是 40%？和 BERT 的 15% 差这么多？
A：图像的信息冗余度远高于文本——相邻像素高度相关，遮 15% 时模型靠邻域插值就能”猜”出答案，任务太简单、学不到语义。BEiT 用约 40%，MAE 更高（75%），因为 MAE 只编码可见 patch，遮得越多反而越省算力，同时任务足够难才能逼出语义理解。

Q4：为什么损失只算被遮位置？
A：可见位置的输出对”重建”没有监督意义（答案就在输入里），算进去只会让模型学会”抄输入”。只对被遮位置算 loss，才是真正的”从上下文推断”。

Q5：BEiT 的 [CLS] token 有什么用？
A：预训练阶段它是 ViT 的全局聚合位（和所有 patch 做注意力），预训练结束后丢弃 Masked Head，把 [CLS] 的输出接一个线性层做下游图像分类——这与 BERT 的用法完全一致。注意 MIM 损失不作用在 [CLS] 上。

Q6：MIM 和对比学习能结合吗？
A：能，且是后续主流方向之一。例如 BEiT v2 引入”语义-rich 的 tokenizer”+ 中间层特征蒸馏；也有工作把对比损失与 MIM 损失联合优化（iBOT 一类）。讲师在本章把它们并列为两条路线，是为了讲清楚”造标签的三种方式”，实际 SOTA 模型常做融合。

十、小结

本节用 5 分钟讲清了自监督学习的第三条路，核心可以压缩成三句话：

  1. 思想：把 NLP 的 BERT 完形填空搬到 CV——遮住图像的若干 patch，让网络从上下文把被遮内容”填”回来，这个过程逼它学到图像的结构与语义（MIM）。
  2. 关键改造：图像是连续信号，”填像素”是回归、”填词”才是分类。BEiT 先用 dVAE tokenizer 把每个 patch 映射成 8192 词表中的一个视觉 token，从而把任务变成标准的 8192 类分类。
  3. 目标函数： ——外层对该 batch 所有样本求和、内层对所有被遮位置求和、最内层是被遮位置”填对词”的概率（一个 Linear + softmax），实现上就是 F.cross_entropy(logits, labels)。

与前后章节的关系：

  • 向前：P2 的”前置任务”、P3–P5 的”对比学习”，加上本节的”掩码重建”，共同构成自监督学习的完整版图；
  • 向后：本章结束后进入视觉大模型（P7 的 ViT 是 BEiT 的骨架、P11 的 MAE 是 MIM 的另一条分支）。理解了本节，才能看懂 MAE 为什么敢”只编码可见 patch”、为什么”遮 75% 反而更好”。

一句话记住本节：BEiT = 视觉版 BERT，靠”先造词典（dVAE tokenizer）、再做视觉完形填空（ViT + 线性分类头 + 交叉熵）”来无监督地学图像表征。
