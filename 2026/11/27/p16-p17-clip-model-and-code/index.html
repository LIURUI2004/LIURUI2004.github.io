二、动机：从「固定标签」到「自然语言监督」

传统图像分类的范式是：定义 1000 个类别 → 收集标注 → 训 softmax。它有三个硬伤：

  1. 标签空间是封闭的：模型只会认训练时出现过的类别，出现新类就要重训；
  2. 标注昂贵：ImageNet 级别的细粒度标注需要大量人工；
  3. 标签信息量低：「这是一只狗」丢掉了品种、姿态、场景等所有细节。

CLIP 的替换方案是用自然语言当监督信号：互联网上存在海量「图片 + 它的说明文字」，从网页 alt-text、社交媒体配文里可以爬到 4 亿对（论文补充：WebImageText, WIT）。文本描述天然是开放的、信息量丰富的、免费的。

于是任务从「分类」变成了「判断这张图和哪段文字配对」——这正好是一个可以自监督构造的任务：batch 内 N 个图文对，天然有 1 个正样本和 N−1 个负样本，不需要人工标注。

三、架构：双塔 + 一个相似度矩阵

3.1 图像编码器

论文试了两种（论文补充）：

骨干 说明 用途
ResNet-50 / ResNet-101 传统 CNN，配合 ResNet-D 改进 + 抗锯齿下采样 与 ViT 对比的基线
ViT-B/32、ViT-B/16、ViT-L/14 把图像切 patch 的 Transformer（第三章的主角） 最终发布的主模型

讲师在 P16 里特别点了一句：CLIP 是把 ViT 用得最彻底的工作之一，第三章讲的 ViT 在这里第一次被大规模图文数据训练，并证明了「ViT 在数据足够多时碾压 CNN」。

3.2 文本编码器

标准的 Transformer encoder：12 层、宽度 512、8 个注意力头、约 6300 万参数（论文补充）。文本经 BPE 分词，最长 77 个 token，取 [EOS] 位置的输出作为整句表示，再做 LayerNorm + 线性投影。

为什么取 EOS 而不是 [CLS]：CLIP 论文的做法是取序列最高位（EOS token）的隐状态，因为它能「看到」前面所有 token，并且与因果语言模型的用法保持一致（讲师在 P16 里画面标注了这一步）。

3.3 投影到共享空间

两个塔的输出各自过一层线性投影，映射到同一个 $d$ 维空间（讲师代码用 512；论文最大模型用 1024），再做 L2 归一化，使得相似度计算退化为余弦相似度。

$$\hat{u}_i=\frac{W_I f_I(I_i)}{\|W_I f_I(I_i)\|_2},\qquad \hat{v}_j=\frac{W_T f_T(T_j)}{\|W_T f_T(T_j)\|_2},\qquad s_{ij}=\hat{u}_i^{\top}\hat{v}_j\in[-1,1]$$

3.4 N×N 相似度矩阵：一次前向拿到 2N 个任务

一个 batch 有 N 对图文，算出 $N\times N$ 的相似度矩阵 $S$：

  • 对角线 $s_{ii}$：正确配对，是正样本；
  • 非对角线 $s_{ij}\ (i\neq j)$：错配，是负样本；
  • 一次矩阵乘法就构造出 $2N^2-2N$ 个负样本 —— 这是 CLIP 训练效率高的根本原因。

讲师把这一句总结成：「batch size 就是负样本数量」。因此 CLIP 的训练极其依赖大 batch（论文用 32768），batch 小了负样本不够，效果会明显下降。

四、损失函数：对称 InfoNCE

对每一行（固定图像找文本）和每一列（固定文本找图像）各做一次 N 类交叉熵，再取平均：

$$\mathcal{L}_{I\to T}=-\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp(s_{ii}/\tau)}{\sum_{j=1}^{N}\exp(s_{ij}/\tau)}$$
$$\mathcal{L}_{T\to I}=-\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp(s_{ii}/\tau)}{\sum_{j=1}^{N}\exp(s_{ji}/\tau)},\qquad \mathcal{L}=\frac{\mathcal{L}_{I\to T}+\mathcal{L}_{T\to I}}{2}$$

两个要点：

  1. 为什么要对称：只做 $I\to T$ 时，模型只需保证「每个图像找到自己的文本」，可能形成「少数文本被很多图像抢」的塌缩；反向再做一次，要求「每个文本也要唯一地找到自己的图像」，双向约束才能让空间均匀；
  2. 温度 $\tau$ 是可学习的（论文补充）：官方实现把它参数化成 $\tau=\exp(\text{logit_scale})$，并对 logit_scale 设上限 100（即 $\tau\ge 0.01$），防止训练早期把温度压得过小导致梯度爆炸。讲师代码里也用 logit_scale 这个写法。

五、零样本分类：用语言「造」一个分类头

这是 CLIP 最漂亮的地方。给定 K 个类别名，不需要一张训练图：

  1. 每个类名套一个模板，生成 K 条文本：a photo of a {class}；
  2. 用文本编码器把 K 条文本编成 K 个单位向量，堆成矩阵 $W_c\in\mathbb{R}^{K\times d}$——这就是分类头的权重；
  3. 图像编码器把待分类图像编成 $\hat{u}$；
  4. 做相似度 $W_c\hat{u}$，取 argmax，必要时再过 softmax 得到概率。
$$\hat{y}=\arg\max_{k}\;\hat{u}^{\top}w_k,\qquad p(y=k\mid I)=\frac{\exp(\hat{u}^{\top}w_k/\tau)}{\sum_{j}\exp(\hat{u}^{\top}w_j/\tau)}$$

讲师强调模板不是可有可无的细节：论文里把 a photo of a {class} 换成裸类别名，ImageNet 零样本精度会掉好几个点；再叠加「同义词平均」（如 dog/puppy/canine 各编一次取平均）还能再涨（论文补充，这一整套叫 prompt engineering / ensembling）。

与传统分类头的本质区别：传统分类头的权重是训练出来的参数，CLIP 的分类头权重是由文本实时生成的。换任务只需换一句话，模型不动。

5.1 论文给出的零样本结果（论文补充）

指标 数值
ImageNet 零样本 Top-1（ViT-L/14@336） 76.2%
与 ResNet-50 有监督（ImageNet 全监督训练）对比 零样本即可持平
覆盖的下游数据集 30+ 个（含 OCR、动作识别、卫星图像等）

注意「持平」的限定条件：CLIP 在通用物体分类上很强，但在需要细粒度专业知识的任务（如区分车型号、肿瘤分类）上不如有监督模型——因为这类知识在互联网图文对里稀缺。

六、P17：把 CLIP 写成代码

6.1 整体结构

讲师的实现分四块，与前面五节一一对应：

模块 对应概念 代码量
ImageEncoder 图像塔 ResNet/ViT 主干 + 投影层
TextEncoder 文本塔 BertModel + 投影层
CLIP.forward 相似度矩阵 归一化 + 矩阵乘 + 温度
clip_loss 对称 InfoNCE 两次交叉熵取平均

6.2 数据：怎么把分类数据集变成图文对

这是教学版最巧的一步：CIFAR-10 本身只有 (image, label)，没有文本。讲师用类别名套模板即时生成文本，等于现场构造图文对：

这个做法的局限必须点出来：10 个类别、模板固定，同一类的文本表示几乎相同，模型实际学到的是「10 个文本锚点 vs 图像」——与 CLIP 用 4 亿对真实描述训练出的细粒度对齐完全不是一个量级。教学价值在于流程正确，不在于效果。

6.3 CLIP.forward：一行矩阵乘就是整个对比学习

三个细节：

  1. 归一化在投影之后、相似度之前：若在投影前归一化，投影层的缩放会破坏单位球假设；
  2. logit_scale.exp().clamp(max=100)：对应论文的「温度下限 0.01」，防止后期温度退化成硬 max；
  3. img_feat @ txt_feat.t()：得到 (B,B)，行是图像、列是文本，logits[i][i] 是正样本。

6.4 损失：两次交叉熵

labels = arange(N) 是整段代码的灵魂：它把「图文配对」这个任务伪装成 N 分类问题——第 i 张图属于第 i 类，交叉熵自动把非对角线的分数压下去。

6.5 训练循环

drop_last=True 不是可选项：若最后一个 batch 只剩 1 个样本，相似度矩阵是 1×1，损失恒为 0，梯度无意义。

6.6 跑通后的自检

若这个准确率一直停在 $1/N$ 附近（如 256 分类的 0.4%），说明没学到东西，优先检查：两个塔是否都参与了梯度、F.normalize 是否漏写、logits.t() 是否方向写反。

七、教学版与官方实现的差异

维度 讲师教学版（P17） 官方 CLIP
数据 CIFAR-10，10 类，文本由模板生成 4 亿真实网页图文对
图像塔 ResNet-50，2048→512 ResNet 或 ViT-B/32…ViT-L/14@336
文本塔 BERT-base，768→512 12 层 512 宽 Transformer，取 EOS
batch 256 32768
负样本 255 个 3 万+
温度 可学习，clamp 到 100 可学习，clamp 到 100（相同）
损失 对称交叉熵 相同（对称 InfoNCE）

差异几乎全在规模上，而损失与架构是同一套。换句话说：CLIP 的贡献不是新损失函数，而是「这个简单目标 + 巨大数据 + 大 batch」这个组合的可扩展性。

八、本篇要点核对清单

  • 动机：用自然语言监督替代封闭标签空间，负样本来自 batch 内错配
  • 双塔架构：图像塔（ResNet/ViT）+ 文本塔（Transformer）+ 各自投影到共享维度 + L2 归一化
  • N×N 相似度矩阵：对角线正样本，一次前向获得 $2N^2-2N$ 个负样本，故依赖大 batch
  • 对称 InfoNCE 的完整式子与「为什么必须对称」
  • 可学习温度 $\tau$ 及其上限 100 的原因
  • 零样本分类：文本编码器即分类头权重，prompt 模板与同义词集成的影响
  • 代码三处易错点：归一化位置、logit_scale.clamp、logits.t() 对称损失
  • 教学版与官方版的差异集中在规模，而非目标函数
