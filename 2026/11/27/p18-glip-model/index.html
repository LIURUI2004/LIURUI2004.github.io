4.5 GLIP 模型

一、视频信息与定位

分P P18（4.5 GLIP 模型），时长 275 秒（4:35）
关键论文 Li L H, Zhang P, Zhang H, et al. Grounded Language-Image Pre-training. CVPR 2022（微软）
本节定位 P15 分类里的类型 B（融合式）。CLIP 做到的是「整图 ↔ 整句」的对齐；GLIP 把粒度往下推了一层，做到「图像区域 ↔ 单词」的对齐，于是检测这个原本需要固定类别词表的任务，变成了可以用自然语言指定类别的任务。

二、动机：检测的类别词表是封闭的

传统检测器（Faster R-CNN、DETR、YOLO）的输出层是一个长度为 K 的分类头，K = 训练集类别数。这带来和 CLIP 之前分类任务一样的问题：

  • 换类别 → 改分类头 → 重训；
  • 训练集里没有的类（稀有物种、专业零件）永远检测不到；
  • 类别名是孤立的 ID，模型不知道「狗」和「哈士奇」有关系。

GLIP 的判断很直接：检测不必是「分类」，可以是「匹配」。给模型一句话「person. dog. cat.」，让它把句子里的每个名词与图像中的区域对上——这就是 grounding（把语言落地到图像）。

于是检测任务的监督信号从「框 + 类别 ID」变成了「框 + 短语」，可以用大规模图文数据（如 caption、region-caption 对）自己造出来。这正是标题里的 Grounded pre-training：半监督——图像级有文本、框级有一部分标注，两者混合训练。

三、把检测变成「词–区域对齐」

3.1 prompt 的构造方式

GLIP 的输入 prompt 就是把类别名用句号连成一句话：

（讲师画面里就是这种形式，P18_50）。文本编码器输出逐 token 的特征 ，其中落在名词上的那些 token（”person”、”dog”、”cat”）才是真正要用的「类别原型」；句号、虚词只是分隔符，但因为参与了上下文编码，它们让每个名词的特征带上了「这是一个独立类别」的语境。

与 CLIP 的关键差别：CLIP 的文本塔输出整句的一个向量（取 EOS），一句话只有一个表示；GLIP 需要句子中每个词的表示——因为要逐词与区域匹配。讲师特意在 P18_130 指向了「Word Features」这一块。

3.2 deep fusion：为什么要让视觉和文本早融合

如果两个塔完全独立（像 CLIP 那样），图像侧的视觉特征根本不知道文本里有什么词，它只是被动地被拿去和文本比相似度。GLIP 的做法是：在视觉编码器的多层之间插入与文本 token 的 cross-attention，让视觉特征在形成过程中就「看到」文本（P18_90、P18_250）。

其中 是区域特征（M 个候选区域的表示）。这一步在论文里由 DyHead（Dynamic Head）模块承担，融合发生在多个尺度上（论文补充：GLIP-T 用 Swin-T 视觉骨干 + DyHead，融合层 6 层）。

好处很直白：视觉特征被文本条件化了。同一个区域，在 prompt 是 “person. dog.” 时和 prompt 是 “car. tree.” 时会得到不同表示，从而更容易对上调。

3.3 word-region 对齐分数

融合后，区域特征与词特征做点积，得到「每个区域 ↔ 每个词」的对齐分数矩阵（P18_170、P18_270）：

其中 是候选区域数、 是类别（词）数。这个矩阵同时承担了两件事：

  • 检测：对每个区域取 与阈值比较，超过阈值就认为存在该类的框；
  • 对齐：训练时把 当作 logits，用「区域是否真的对应这个词」作为标签算损失。

也就是说，检测头和图文匹配头被合并成了一个矩阵——这是 GLIP 最核心的架构简化。

两项的分工要记清楚：对齐损失负责「认得出是什么」，定位损失负责「框得准不准」。只有图像级文本没有框标注的样本，只参与对齐损失——这就是「半监督」的具体体现。

五、结果与影响

结论 说明
零样本检测可行 在没见过目标数据集的情况下，直接在 COCO/ LVIS 上评估，AP 远超此前的零样本检测方法
少样本迁移快 给定少量标注样本微调，10-shot 级就能接近全监督的相当一部分性能（论文补充）
类别可自由指定 改 prompt 里的词即可新增/替换类别，不需要改网络结构、不需要重训（P18_50）
成为后续工作的基础 Grounding DINO、GLIP-v2、以及各类「开放词表检测」都沿着这条路线

讲师在这里做了一个重要的定位判断：GLIP 不是「又一个检测器」，而是把检测纳入了多模态预训练的框架——它证明了「图像区域」这个粒度也可以和语言对齐，从而让检测、分割、检索共享同一套语义空间。

六、与 CLIP 的对比

维度 CLIP（P16） GLIP（P18）
对齐粒度 整图 ↔ 整句 区域 ↔ 单词（region-word）
两塔是否交互 否，最后才比相似度 是，多层 cross-attention 深度融合
文本表示 单个句向量 逐词特征序列
输出 相似度分数 相似度矩阵 + 检测框
监督方式 图像级图文对（自监督式对比） 图像级文本 + 框级标注（半监督）
架构类型（P15） 类型 A 双塔 类型 B 融合
训练成本 低（可预计算文本） 高（每样本都要联合前向）

一句话：CLIP 让「图」和「文」对齐，GLIP 让「图中某一小块」和「文中的某一个词」对齐。

七、实践提示

  1. prompt 写法直接影响效果：论文的消融显示把类别名连成一句（而非逐个单独编码）能提升 AP，因为名词之间有了上下文；
  2. 融合层越深越贵：deep fusion 是多层交叉注意，训练成本随融合层数线性上升，实际部署常在浅层融合；
  3. 负样本构造靠区域：与 CLIP 的 batch 内负样本不同，GLIP 的负样本来自「不匹配的区域-词对」，因此对 batch 内区域数量敏感；
  4. 开放词表不等于万能：prompt 里没出现概念、或概念在预训练文本中极少出现（专业术语、罕见物种），效果仍会掉。

八、本篇要点核对清单

  • 动机：检测的固定类别头 → 用 grounding 把检测改成图文匹配
  • prompt 构造：类别名连成句子，取名词位置的逐词特征
  • deep fusion：视觉多层与文本 token 做 cross-attention，使视觉特征被文本条件化
  • word-region 对齐分数矩阵 同时承担检测与对齐
  • 损失构成：对齐损失（focal 形式） + 定位损失（GIoU/L1）
  • 与 CLIP 在粒度、交互、监督方式、成本上的六点差异
  • GLIP 的历史位置：开放词表检测与 Grounding DINO 的源头
