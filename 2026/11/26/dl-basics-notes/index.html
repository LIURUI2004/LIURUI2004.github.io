从 MLP、归一化到 Transformer、多模态与 SAM2 变化检测

核心示意：MLP 做的是特征加工，不是一个神秘的“智能模块”。

这份笔记怎么用？ 每个知识点按“是什么 → 为什么需要 → 在哪里出现 → 代码长什么样 → 容易误解什么”展开。先理解用途，再记名字。

面向读者：正在学习 PyTorch、多模态项目，以及弱监督 SAM2 遥感变化检测的初学者。

第一部分：先弄懂神经网络处理的数据

1. Tensor（张量）

一句话记忆：Tensor 是神经网络中的数据容器，可以理解为带有多个维度的数组。PyTorch 中，图片、特征、标签、模型参数基本都以 Tensor 的形式出现。

  • 标量：一个数，例如 loss = 0.35，通常没有维度。
  • 向量：一串数，例如一个 256 维特征，shape = [256]。
  • 矩阵：二维表，例如 64×64 的表格，shape = [64, 64]。
  • 高维张量：图像批次常见 [B, C, H, W]。

遥感图像例子 [8, 3, 256, 256] 表示一次送入 8 张 RGB 图像；3 是颜色通道，256×256 是图像高和宽。

2. Shape（张量形状）

一句话记忆：shape 描述每个维度有多少个元素。它是阅读和调试深度学习代码最重要的信息之一。网络报维度错误时，第一步通常是打印参与运算的张量形状。

3. Feature / Feature Map（特征 / 特征图）

特征是模型从输入中提取出的数字表示。比如一张遥感图像里，浅层特征可能响应边缘、纹理和局部颜色；更深层的特征可能包含建筑、道路等更抽象的信息。Feature Map（特征图）强调这些特征仍按空间位置排列。

4. Channel（通道）

通道可以粗略理解为“每个空间位置上有多少个特征数值”。RGB 图片有 3 个颜色通道；神经网络特征图可能有 64、256、1024 个通道。通道数不是图片的 RGB 颜色数，而是模型学出来的特征维度。

5. Token / Patch（词元 / 图像块）

Transformer 常把输入拆成一串 token。文本 token 通常来自词或子词；视觉模型可以把图像切成 patch，再把每个 patch 编码成向量。于是二维图像可以表示成 N 个视觉 token，每个 token 有 D 维特征，即 [B, N, D]。

图 1 CNN 特征图、Token 序列与 MLP 输入形状之间的关系。

第二部分：MLP 专题——它到底有什么用？

6. Linear（线性层 / 全连接层）

一句话记忆：Linear 对输入特征做可学习的加权组合，并可以改变特征维度。它不是简单地“复制或裁剪数字”，而是学习一套权重，让输入的不同维度相互组合。

数学形式：y = Wx + b。W 是训练得到的权重矩阵，b 是偏置。训练过程会调整 W 和 b，让输出更有利于完成任务。

什么时候会见到 Linear？ 特征维度转换、分类头、图文向量投影、注意力中的 Q/K/V 投影，以及 MLP 内部。

7. MLP（Multi-Layer Perceptron，多层感知机）

先记住最重要的一句话 MLP 的目的：学习“一个特征向量内部，不同特征维度应该怎样组合”，把原始特征加工成更适合当前任务的表示。它是一个通用的特征加工器，不是专门负责注意力、分割或变化检测的模块。

把一个 token 或一个像素位置的特征想成一张小清单：第 1 维可能对边缘响应强，第 2 维可能对纹理响应强，第 3 维可能对形状响应强……这些数字单独看并不一定够用。模型需要学习它们如何组合，例如哪些维度一起出现时更有用。MLP 就负责学习这种组合关系。

图 2 两层 MLP：先把特征映射到隐藏维度，经非线性加工，再映射到目标维度。

7.1 MLP 每一步到底在做什么？

  • 输入 x：一组已有特征，例如长度为 4 的向量。它已经是前面 Encoder 提取出来的表示。
  • 第一层 Linear：用 W₁ 和 b₁ 对输入做加权组合，并把维度从 4 变成 8。扩展维度是为了给模型更大的中间表示空间。
  • GELU / ReLU：引入非线性。它让整个网络不再只是简单的一次线性映射，能够表达更复杂的特征关系。
  • 第二层 Linear：把隐藏表示再映射到需要的维度，例如从 8 维映射回 4 维，方便后续模块继续处理，也常便于和残差输入相加。

7.2 为什么不只用一层 Linear？

多个 Linear 如果中间没有非线性激活，数学上仍可合并成一个 Linear。也就是说，单纯堆叠线性层不会带来更强的非线性表达能力。MLP 中间的 GELU / ReLU 是关键：它改变中间响应，使模型可以学习更复杂的组合关系。

7.3 为什么经常先扩展再压缩维度？

Transformer 的 FFN 常见维度变化是 D → 4D → D（具体比例由模型设计决定）。先扩展相当于给特征组合提供更宽的中间空间，再通过激活和第二层映射回 D。这样输出维度与输入一致，便于接残差连接。4 倍不是自然定律，而是常见设计选择。

7.4 MLP 具体“用在哪里”？

图 3 MLP 常见的三种放置位置。

位置 A：Transformer Block 里的 FFN

Attention 之后通常会接一个 MLP / FFN。Attention 先让不同 token 交换信息；MLP 再对每个 token 自己的特征通道进行加工。它们分工不同。

位置 B：多模态的 Projection / Adapter

图像编码器和文本编码器的输出可能维度不同、数值分布也不同。可以用 Linear 或 MLP 把视觉向量、文本向量映射到共同维度或适配空间，便于后续做相似度计算、对齐或融合。注意：投影不一定必须是 MLP，有时一层 Linear 就够了。

位置 C：预测头 / 质量评估头

融合后的特征可以送入 MLP，输出分类 logits、置信度或质量分数。此时 MLP 负责把特征变成任务所需的数值；输出含义由它连接的监督目标决定。

7.5 MLP 与 Attention 的区别

图 4 Attention 跨 token 交互；MLP 在每个 token 内部加工通道。

对输入 X [B, N, D] 来说，N 是 token 数，D 是每个 token 的特征维度。标准 Transformer FFN 通常对每个 token 独立应用同一组 MLP 权重：不改变 N，主要变换 D。Attention 则会计算 token 之间的关系，让一个位置汇总其他位置的信息。

7.7 MLP 不是什么？

  • MLP 不等于 Attention：普通 MLP 不会自动让不同 token 互相查看。
  • MLP 不等于分类器：只有当它的输出被设计成类别分数并用分类损失训练时，才承担分类头角色。
  • MLP 不保证语义可解释：不能直接说某个隐藏神经元一定代表“建筑边缘”，除非做了专门分析。
  • MLP 不一定改变空间分辨率：对 [B,N,D] 的 token MLP 通常不改变 N；对图像特征图怎么处理取决于实现。

8. MLP 在 SAM2 与你的变化检测任务中怎么理解？

要把“基础模型内部原本就有的 MLP”和“你自己设计的变化检测头里的 MLP”区分开。它们可能都叫 MLP，但服务的任务不同。

8.1 SAM2 内部确实会用 MLP

以 Meta 官方 SAM2 实现为例，Mask Decoder 中包含用于预测掩膜质量（IoU / quality score）的 MLP，也包含用于生成掩膜相关动态权重的 hypernetwork MLP；TwoWayTransformer 的 block 里也有 MLP。也就是说，MLP 是 SAM2 结构内部用于特征加工和预测的常用部件，不是 SAM2 的全部。

8.2 在弱监督变化检测里，MLP 可能放在哪里？

  • 双时相特征融合之后：把 [F₁, F₂, |F₁−F₂|] 等融合特征进一步加工。
  • 变化预测头中：把像素 / patch 特征转换成变化 logits。对于空间密集预测，通常也会结合卷积、上采样等操作。
  • 特征适配器中：把冻结 SAM2 Encoder 的输出通道映射到轻量变化检测器需要的维度。
  • 具体例子：如果把 T1 特征 F1、T2 特征 F2 和差异特征 |F1-F2| 拼接后送入 MLP，MLP 学的是如何重新组合这三类信息，让下游预测头更容易判断变化。
  • 反过来，如果 MLP 只接收 T2 的单时相特征，它本身没有 T1 信息，不能单独完成双时相变化比较。

对你的论文最重要的判断原则 不要为了“用了 MLP”就把它当成创新点。MLP 是基础组件。真正需要解释的是：为什么把它放在这个位置、它针对现有方法的哪个缺陷、与 Conv / Linear / Attention 等替代方案相比有什么收益，以及消融实验是否支持这个设计。

第三部分：归一化、残差与激活函数

9. Normalization（归一化）

一句话记忆：归一化按指定维度计算统计量，调整特征的数值尺度，让不同样本或不同通道的数值不要因为尺度差异而让训练变得不稳定。常见操作是减均值、除以标准差，再通过可学习参数进行缩放和平移。

10. BatchNorm（BN，批归一化）

BN 在视觉 CNN 中很常见。以 BatchNorm2d 为例，对每个通道分别统计 batch 维和空间维（H、W）上的均值与方差。训练阶段使用当前 batch 的统计量，同时更新运行统计量；推理时通常使用运行统计量。

11. LayerNorm（LN，层归一化）

LN 通常对单个样本的指定特征维度计算均值和方差，不依赖同一个 batch 里的其他样本。Transformer 中常见输入形状 [B, N, D]，LayerNorm(D) 通常对每个 token 的最后一维 D 做归一化。

12. BN 和 LN 最容易混淆的地方

图 5 BN 与 LN 的统计维度示意。具体维度由输入形状和模块参数决定。

  • BN：统计量通常跨 batch 和空间位置，对每个通道分别计算；推理行为会用到运行统计量。
  • LN：对每个样本的指定特征维度计算；不需要依赖 batch 中其他样本。
  • 不要死记 BN 只用于图像、LN 只用于文本。要看张量形状、归一化轴和网络设计。

13. GroupNorm / InstanceNorm / RMSNorm

  • GroupNorm：把通道分成若干组，每组内部归一化；不依赖 batch 统计，小 batch 视觉任务中可能更合适。
  • InstanceNorm：通常对每个样本、每个通道分别按空间维归一化，在图像风格任务中常见。
  • RMSNorm：按均方根尺度进行缩放，通常不做 LayerNorm 那样的减均值操作，在 LLM 中较常见。

14. Activation（激活函数）

激活函数为网络加入非线性表达能力。没有非线性时，多个线性层叠起来仍然只是线性变换。

  • ReLU：负数变为 0，正数保持不变。
  • GELU：平滑地调节输入值，Transformer / MLP 中常见。
  • Sigmoid：把单个数压缩到 0～1，常用于二分类概率或门控系数。
  • Softmax：把一组分数转换成总和为 1 的类别概率，常用于多分类。

15. Residual Connection（残差连接 / 跳跃连接）

一句话记忆：让输入绕过某个模块，再与模块输出相加。这样网络可以在保留原始信息的基础上学习“需要增加或修正的部分”，也有利于梯度传播。

16. Transformer Block 中这些模块如何配合？

图 6 一个常见 Pre-Norm Transformer Block 的简化结构。

先归一化，再通过 Attention 让 token 之间交流，然后残差相加；接着再归一化、通过 MLP 加工每个 token 的通道，最后再做一次残差相加。不同架构可以使用 Pre-Norm 或 Post-Norm，实际顺序以论文和代码为准。

第四部分：Transformer 与多模态高频模块

17. Attention（注意力机制）

Attention 让一个 token 根据相关程度，从其他 token 或另一种模态中汇总信息。它的关键不是“注意力”这个名字，而是计算权重并用权重对信息进行加权组合。

18. Q、K、V

Q（Query）可以理解为“我想找什么”；K（Key）是“我可以用什么特征来匹配”；V（Value）是“匹配后真正取走的信息”。Q 与 K 得到匹配分数，Softmax 转成权重，再用权重汇总 V。

图 7 Self-Attention 的 Q/K/V 数据流。

19. Self-Attention 与 Cross-Attention

  • Self-Attention：Q、K、V 来自同一组输入，建模同一模态或序列内部的关系。
  • Cross-Attention：Q 来自一组特征，K/V 来自另一组特征。例如文本 token 作为 Q，图像 patch 特征作为 K/V，实现文本查询图像信息。

20. Multi-Head Attention（多头注意力）

把注意力计算拆成多个头，让不同头在不同子空间中学习关系，再把各头结果合并。多个头不保证一定学到人类可解释的不同语义，但提供了并行表达关系的能力。

21. Positional Encoding / RoPE（位置编码）

Attention 单独看集合关系时，不天然知道 token 的位置顺序。位置编码把位置信息加入特征或注意力计算。RoPE（旋转位置编码）通过对 Q/K 做旋转变换，将位置信息融入注意力计算。视觉模型还需要考虑二维空间位置信息。

22. Encoder / Decoder（编码器 / 解码器）

Encoder 把原始输入变成特征表示；Decoder 根据特征生成任务输出，例如掩膜、类别或文本。不要把所有叫 Encoder 的模型都理解成完全相同的结构，它只是“编码输入”的功能角色。

23. Projection（投影层）

Projection 把特征映射到指定维度或表示空间，常用 Linear 实现。多模态对齐时，常把视觉向量和文本向量投影到相同维度；但维度相同不等于语义已经自动对齐，还需要相应训练目标。

第五部分：训练模型时常见的词

24. Forward（前向传播）

输入经过模型计算，得到预测结果。PyTorch 中通常由 model(x) 调用 forward()。

25. Loss（损失函数）

衡量预测与监督信号的差距。训练目标通常是降低 Loss。

26. Backpropagation（反向传播）

从 Loss 出发，利用链式法则计算每个可训练参数的梯度。

27. Gradient（梯度）

表示参数变化对 Loss 的影响方向和幅度。梯度不是参数本身。

28. Optimizer（优化器）

根据梯度更新参数。常见 SGD、Adam、AdamW。

29. Learning Rate（学习率）

控制每次参数更新的步长。太大可能震荡或发散，太小可能收敛慢。

30. Dropout（随机失活）

训练时随机将部分输出置零，降低模型对少数通道的依赖，有助于缓解过拟合。

31. Freeze / Fine-tuning（冻结 / 微调）

Freeze 表示某些参数不更新；Fine-tuning 表示用目标任务数据继续训练预训练模型。

32. LoRA

一种参数高效微调方法：冻结大部分原模型参数，只训练额外的低秩适配参数，降低训练成本。

33. 三种变化检测里经常见到的 Loss

  • BCE（Binary Cross Entropy）：常用于二分类像素预测，例如每个像素是否变化。
  • Cross Entropy：常用于多类别分类。
  • Dice Loss：关注预测区域与真实区域的重叠程度，常用于分割。
  • 弱监督训练时，Loss 对应的监督可能是图像级标签或伪标签，不一定是真实像素级标注。

第六部分：把基础模块放回 SAM2 变化检测

34. 双时相变化检测究竟多了什么？

单幅图像分割只需要回答“这张图里目标在哪里”；变化检测要比较两个时间点，回答“哪些位置发生了变化”。因此模型需要从 T1、T2 提取特征，再设计时相比较或融合机制。

图 8 面向弱监督 SAM2 变化检测的概念流程。

35. SAM2 里常见模块的功能

  • Image Encoder：从图像提取视觉特征。
  • Prompt Encoder：把点、框、掩膜等提示信息编码为提示特征。
  • Mask Decoder：结合图像特征和提示特征生成分割掩膜。
  • Transformer / MLP：在解码器内部处理 token 特征或预测掩膜质量等信息。

36. SAM2 本身能不能直接做变化检测？

不能简单等同。SAM2 是提示式图像 / 视频分割模型；它的原生目标不是比较两个独立时相并输出变化图。变化检测方法通常还要增加双时相特征提取、差异建模、融合和变化预测过程。

37. 对你的弱监督方法，MLP 最值得关注的三个问题

  • MLP 的输入是什么？例如 F₁、F₂、|F₁−F₂|，还是某一层 SAM2 特征？
  • MLP 的输出是什么？是新的融合特征、像素变化 logits、伪标签置信度，还是 mask quality score？
  • MLP 的 Loss 从哪里来？是图像级标签、伪标签，还是其他监督？这决定了它到底在学习什么。

读论文时不要只看模块名字 把模块前后的张量 shape、计算公式、监督来源一起看。一个模块的功能，是由“输入—运算—输出—训练目标”共同决定的。

第七部分：代码速查与排错清单

代码 / 名词 快速理解 常见用途
nn.Linear(a,b) 最后一维 a → b 的可学习线性映射 MLP、投影、分类头
nn.Conv2d 局部空间卷积 CNN、变化检测头
nn.BatchNorm2d 对每通道按 batch/空间统计 CNN 特征图
nn.LayerNorm 对指定特征维归一化 Transformer token
nn.GELU / nn.ReLU 非线性激活 MLP / FFN
nn.Embedding 离散 ID 查可学习向量 文本 token、类别 ID
torch.cat 沿已有维度拼接张量 拼接 T1/T2 特征
torch.stack 新增维度后堆叠张量 组织多路特征
permute / transpose 调整维度顺序 [B,C,H,W] ↔ [B,H,W,C]
reshape / view 改变张量形状（元素总数不变） 展平空间维
loss.backward() 计算梯度 反向传播
optimizer.step() 更新参数 训练循环
requires_grad=False 冻结参数 冻结预训练 Encoder

调试时先问自己的 6 个问题

  • 这个张量的 shape 是什么？B、C、H、W、N、D 各代表什么？
  • 这个模块改变的是维度、空间分辨率，还是特征内容？
  • 如果有两个时相，当前模块是否真的接收了 T1 和 T2 的信息？
  • 这个 MLP 是逐 token 操作，还是先把图像特征展平后操作？
  • 这个输出代表特征、概率、logits、掩膜，还是质量分数？
  • 这个模块的参数是否参与训练？requires_grad、optimizer 参数组和梯度是否符合预期？
